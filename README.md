# CSCI218 Rice Dataset Classification

## Description
This project classifies rice types (Osmancik and Cammeo) using various machine learning models:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest

The dataset is from the UCI Machine Learning Repository: [Rice Dataset](https://archive.ics.uci.edu/ml/datasets/Rice+%28Cammeo+and+Osmancik%29).
